## 🧪 Rick and Morty Explorer (React Class Components)

A simple React application built with **class components** that allows users to search and browse characters from the Rick and Morty API. The project demonstrates core React concepts such as lifecycle methods, state management, error handling, and API integration.

This project was set up using Vite with the React + TypeScript template.

---

### 🚀 Features

- 🔍 Search characters by name
- 💾 Persistent search using Local Storage
- 📄 Display character information (name, status, species, gender)
- 📡 Fetch data from public Rick and Morty API
- ⏳ Loading state indicators during API requests
- ⚠️ Error handling for failed requests
- 🧱 Error Boundary with fallback UI
- 📱 Responsive layout for mobile and desktop
- 🧩 Built using React class components (no hooks)

---

### 🛠️ Tech Stack

- React (Class Components)
- TypeScript
- Tailwind CSS
- Vite
- Rick and Morty API

---

### ⚙️ Installation

| Step                   | Command                |
| ---------------------- | ---------------------- |
| Clone repository       | `git clone <repo-url>` |
| Install dependencies   | `npm install`          |
| Run development server | `npm run dev`          |
| Build project          | `npm run build`        |
| Preview build          | `npm run preview`      |
